## The locked recipe (all 8, no skipping)

1. **100% 3D animation look** — dark cinematic spy-thriller grade. Near-black
   backgrounds, warm tungsten practicals, cool rim light, crushed blacks,
   reflective dark floors. Semi-realistic stylized (Unreal/Blender cinematic).
   Vertical 9:16. NEVER bright daytime scenes.
2. **3D typography as objects** — cracked-gold extruded title cards for names,
   metallic-silver stone text for numbers/money, translucent glossy 3D relief
   maps (electric blue / neon green) with glowing outlines + white extruded text.
3. **Documents are 3D props** — evidence boards with pinned faux photos/maps,
   case files, ID cards on lanyards, paper stacks. Realistic, NOT readable real
   documents. (Straight truth: the reference has zero real documents.)
4. **Edit rhythm** — 8-10 shots per ~60s, hard cuts every 4-6 seconds.
   Slow push-ins / gentle orbits within each shot. Occasional map-zoom wipe.
5. **Captions** — white Devanagari, top-third center, semi-transparent black box
   behind, static line swaps (NOT kinetic). Dual-font rendering mandatory:
   NotoSansDevanagari-Bold + DejaVuSans-Bold fallback for Latin
   (Noto Devanagari has NO Latin glyphs). PIL needs RAQM layout engine.
   System fonts only — never download from github raw (returns HTML).
6. **Voice** — single Hindi voiceover, thriller-documentary pacing, same TTS
   voice every reel (avocado_v2:MAI_03, --language hi) for brand recognition.
7. **Score** — tense dark bed under VO (low drone + pulse, subtle, never over VO).
8. **Structure** — giant 3D name title → "let's understand in 3D" hook →
   map per location beat → obstacle scene → prep/money montage →
   black-background mystery/hero finale.
